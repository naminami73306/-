# キー一致転記マクロ（KeyTransfer.bas）

転記元と転記先の Excel ファイルで、それぞれのキー列（別の列でもよい）の値が一致する行について、転記元の指定列の値を転記先の指定列に書き込みます。
結果は、XLOOKUP の結果を「値として貼り付け」したのと同じです。

## 導入（初回だけ）

1. 転記先ファイル、または個人用マクロブック（PERSONAL.XLSB）を開き、`Alt + F11` で VBE を開く
2. メニューから「挿入 → 標準モジュール」を選ぶ
3. `KeyTransfer.bas` の中身を全部コピーして貼り付ける
   - ファイルは UTF-8 で保存しています。日本語版 Windows で「ファイルのインポート」を使うと日本語が文字化けするので、貼り付けで入れてください
4. マクロを入れたブックを `.xlsm`（または PERSONAL.XLSB）として保存する

## 設定

モジュール冒頭の「設定」ブロックだけを書き換えます。

| 定数 | 意味 | 例 |
|---|---|---|
| `SRC_SHEET` / `DST_SHEET` | 転記元 / 転記先のシート名 | `"Sheet1"` |
| `SRC_KEY_COL` / `DST_KEY_COL` | 転記元 / 転記先のキー列（列記号） | `"A"` / `"C"` |
| `SRC_FIRST_ROW` / `DST_FIRST_ROW` | データ開始行（見出し行の次の行） | `2` |
| `COLUMN_MAP` | 転記する列の対応。`転記元列>転記先列` をカンマ区切りで並べる | `"B>E, D>F, H>G"` |
| `SKIP_BLANK_SOURCE` | `True` にすると、転記元が空欄のとき転記先を上書きしない | `False` |
| `NORMALIZE_WIDTH` | `True` にすると、キーの全角/半角と前後の空白を無視して照合する | `True` |
| `MARK_UNMATCHED` | `True` にすると、転記元に見つからなかった転記先のキーセルを黄色にする | `True` |

## 実行

`Alt + F8` → `TransferByKey` → 実行。

1. ダイアログ 1 回目：**転記先**ファイルを選ぶ
2. ダイアログ 2 回目：**転記元**ファイルを選ぶ（読み取り専用で開き、終わったら閉じます）
3. 完了メッセージに件数（転記した行数、転記元にキーが無かった行数、重複キーの件数など）が出ます
4. 転記先ファイルは**保存しません**。中身を確認してから自分で保存してください

既に開いているファイルを選んだ場合は、そのまま使います。転記元と転記先が同じファイル（別シート）でも動きます。

## 動作の前提（ここが合わないと結果がずれる）

- **最終行の決め方**：キー列を下から見て、最後に値がある行までを対象にします。キー列の途中に空欄があっても、その下の行まで処理します（空欄の行は飛ばします）
- **重複キー**：転記元に同じキーが複数ある場合は、上にある行を使います。転記先に同じキーが複数ある場合は、その全部の行に書き込みます
- **書き換える範囲**：キーが一致した行の、`COLUMN_MAP` で指定した転記先セルだけを書き換えます。一致しなかった行の値や数式はそのまま残ります
- **転記する値**：セルの値だけを転記します。数式は計算結果の値になり、書式（色・罫線・表示形式）はコピーしません。`001` のような文字列は、数値に変わらないよう文字列のまま書き込みます
- **キーの照合**：英字の大文字と小文字は区別しません（VBA の Collection の仕様）。数値の `1001` と文字列の `"1001"` は一致します。`001` と `1` は一致しません
- **黄色表示は自動では消えません**：転記元を直して再実行しても、前回黄色にしたセルは黄色のまま残ります。必要なら手で消してください
- Windows / Mac どちらの Excel でも動くように書いています（`Scripting.Dictionary` は使っていません）
