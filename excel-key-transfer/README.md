# キー一致転記マクロ（KeyTransfer.bas）

転記元と転記先の Excel ファイルで、キー（突き合わせに使う列。両者で別の列でもよい）が一致する行について、
転記元の指定した列の値を転記先の指定した列に書き込みます。結果は XLOOKUP を「値として貼り付け」したのと同じです。

**コードを書き換える必要はありません。** 実行すると案内が出るので、シートを見ながらセルをクリックしていくだけで指定できます。

## 導入（初回に1回だけ）

どのファイルからでも使えるように、「個人用マクロブック」に入れるのがおすすめです。

1. Excel で何かファイルを開き、`Alt + F11` を押す（VBE という編集画面が開く）
2. 左の一覧から `VBAProject (PERSONAL.XLSB)` を選ぶ
   - 見当たらない場合：Excel に戻って「表示 → マクロ → マクロの記録」で、保存先を「個人用マクロブック」にして記録開始し、すぐ記録終了する。これで PERSONAL.XLSB ができる
3. メニューから「挿入 → 標準モジュール」を選ぶ
4. `KeyTransfer.bas` の中身を全部コピーして、右側の白い画面に貼り付ける
   - 「ファイルのインポート」は使わないでください（日本語が文字化けします）
5. VBE を閉じる。Excel を終了するとき「個人用マクロブックを保存しますか」と聞かれたら「保存」

### ボタンにしておくと楽（任意）

Excel 左上のクイックアクセスツールバーを右クリック →「クイックアクセスツールバーのユーザー設定」→「コマンドの選択」で「マクロ」を選び、
`PERSONAL.XLSB!TransferByKey` を追加します。以後はそのボタンを押すだけで起動できます。

## 使い方

`Alt + F8` →「TransferByKey」→「実行」（またはツールバーに追加したボタン）。あとは画面の案内に従います。

| 順番 | 画面に出る案内 | やること |
|---|---|---|
| 1 | 転記元のファイルを選んでください | 値を持ってくる側のファイルを選ぶ |
| 2 | 転記先のファイルを選んでください | 値を書き込む側のファイルを選ぶ |
| 3 | 【手順1】転記元のキー | 転記元のシートで、キーの列の**見出しのすぐ下のセル**をクリックして OK |
| 4 | 【手順2】転記先のキー | 転記先のシートで、キーの列の**見出しのすぐ下のセル**をクリックして OK |
| 5 | 【手順3】転記したい列（転記元） | 持ってきたい列のセルをどれか1つクリックして OK |
| 6 | 【手順4】書き込み先の列（転記先） | その値を書き込む列のセルをどれか1つクリックして OK |
| 7 | （5→6 を繰り返す） | 列の組を全部指定したら、手順3の画面で**キャンセル** |
| 8 | この内容で転記します。よろしいですか？ | 見出し名つきの一覧で確認して OK |
| 9 | 転記が完了しました | 件数を確認する |

- シートを切り替えたいときは、案内の画面を出したまま下のシート見出しをクリックすれば切り替わります
- 既に開いているファイルを選んだ場合は、そのまま使います。転記元と転記先が同じファイル（別シート）でも動きます
- 転記元ファイルは、マクロが開いた場合は終わったあと保存せずに閉じます
- **転記先は保存しません。** 中身を確認してから自分で保存してください。おかしかったら保存せずに閉じれば元に戻ります

### 2回目以降

前回の指定（シート名、キーのセル、列の組）を覚えています。
ファイルを選んだあとに「前回と同じ指定で転記しますか？」と聞かれるので、同じでよければ［はい］を押すだけです。
選んだファイルに前回と同じ名前のシートがない場合は、この確認は出ず、最初から指定する流れになります。

## 動作の前提（ここが合わないと結果がずれる）

- **対象の行**：キーの列を下から見て、最後に値がある行までを対象にします。キーの列の途中に空欄があっても、その下の行まで処理します（空欄の行は飛ばします）
- **重複キー**：転記元に同じキーが複数ある場合は、上にある行を使います。転記先に同じキーが複数ある場合は、その全部の行に書き込みます
- **書き換える範囲**：キーが一致した行の、指定した列のセルだけを書き換えます。一致しなかった行の値や数式はそのまま残ります
- **転記する値**：値だけを転記します。数式は計算結果の値になり、書式（色・罫線・表示形式）はコピーしません。`001` のような文字列は、数値に変わらないよう文字列のまま書き込みます
- **キーの照合**：全角/半角と前後の空白は無視します。英字の大文字と小文字は区別しません。数値の `1001` と文字列の `"1001"` は一致しますが、`001` と `1` は一致しません
- **黄色表示**：転記元にキーが見つからなかった行は、転記先のキーのセルを黄色にします。再実行しても自動では消えないので、必要なら手で消してください
- **キーの列には書き込めません**（誤って指定すると止めて選び直しを求めます）
- Windows / Mac どちらの Excel でも動くように書いています

## 詳細オプション（普段は触らなくてよい）

コード冒頭の3行で動作を変えられます。

| 定数 | 意味 | 初期値 |
|---|---|---|
| `SKIP_BLANK_SOURCE` | `True` にすると、転記元が空欄のとき転記先を上書きしない | `False` |
| `NORMALIZE_WIDTH` | `True` にすると、キーの全角/半角と前後の空白を無視して照合する | `True` |
| `MARK_UNMATCHED` | `True` にすると、見つからなかった転記先のキーセルを黄色にする | `True` |
