# 入札「物品の売買」規格適合商品サーチ（Google AI モード用）v1

海上自衛隊 横須賀地方総監部の入札（物品の売買）について、内訳書・仕様書（生糧品の案件は生糧品規格書も）を読み、規格に合う商品を指定した価格で **楽天市場・Yahoo!ショッピング・Amazon** から探すための、Google AI モード（PC版 Chrome）用プロンプト。

- `prompt.md` … AI モードに貼る本体
- `価格指定シート.xlsx` … 価格の指定（入力）と AI の結果（出力・リンク）を1枚で扱う Excel
- `index.md` … 生糧品規格書の品目 → ページ索引
- `example.md` … 実際の公告（G26-S26-2000482994 マヨネーズ（横須賀）以下6件）での記入例

## 使い方（毎回の手順）

1. 入札公告ページ（https://www.mod.go.jp/msdf/bukei/y0/nyusatsu.html）から内訳書の PDF を保存する。
2. 生糧品の案件なら、**規格書から今回の品目のページだけを PDF にする**（下記「規格書の抜き出し方」）。貯糧品の案件なら不要。
3. **`価格指定シート.xlsx`** の黄色の列（A〜G：項目番号・品名・基準量・単位・指定価格・容量下限・上限）に記入する。指定価格は「基準量あたり・税込」。**AI はこの価格を超える商品を探す。**
4. Excel の A2 から、記入した最後の行の G 列までをコピーし、`prompt.md` の【価格表】の位置に貼り付ける。
5. Chrome で google.com の AI モードを開き、`＋` から PDF を添付し、`prompt.md` の中身を貼り付けて送信する。
6. 「A. 内訳書の読み取り結果」を原本と見比べ、間違いがあれば同じスレッドで訂正する。
7. 「C. Excel貼り付け用の表」を見出しごと選択してコピーし、Excel の **H2** に貼り付ける。緑の列に「楽天を開く」等のリンクが自動で出る。「行チェック」が「行ずれ」なら貼り付け位置を直す。
8. リンク先で価格・内容量を必ず確認する（AI の出力は候補であって確定情報ではない）。

※ Google AI モードは Excel ファイルを直接読み書きできないため、コピー＆貼り付けでやり取りする設計にしている。

## 前提として分かったこと（サンプル公告から）

- **内訳書 PDF はスキャン画像**（コピー機 KONICA MINOLTA bizhub 750i でスキャンしたもので、文字データがない）。カーソルで文字を選べないのはこのため。入札公告の本文 PDF には文字データがある。
  → AI モードは画像として文字を読むので、**数字や銘柄の読み間違いが起こりうる**。だから最初に読み取り結果の表を出させ、人が確認する手順を入れた。
- 内訳書の「品名・規格」は、多くが **「一般市販品 横須賀造修補給所糧食品規格書のとおり 銘柄：…」** という形。貯糧品の案件ではこの規格書は存在しないので、内訳書の記載（品名＋銘柄＋単位＋入数）だけで判定する。
- 単位は ZEA（個）／ZCN（缶）／ZBT（本）／ZBX（箱）のようなコードで書かれ、備考に「1ZBX＝30ZBT（1箱＝30本）」のように入数がある。プロンプトでこの読み替えを指定している。
- 銘柄が指定された品目は、指定銘柄以外で応札するには同等品の申請と承認が必要（内訳書2ページ目「6. その他」）。そのため **指定銘柄を優先して探し、他銘柄は「同等品候補」として分けて**出させる。

## 規格書（81ページ）は「該当ページだけを毎回添付」

**なぜ毎回か**：AI モードは前に渡した資料を保持できない。81ページをまるごと添付すると、別の品目の規格と取り違えたり、読み込みが途中で止まったりする危険が大きい。

**抜き出し方（Chrome だけでできる）**：
1. Chrome で規格書 PDF（https://www.mod.go.jp/msdf/bukei/y0/nyuusatsu/seiryouhinnkikakusyo16.pdf）を開く。
2. `Ctrl+P`（印刷）→ 送信先「PDF に保存」→ ページ「カスタム」で該当ページを指定（例：`12,15,31-32`）→ 保存。
3. その PDF を AI モードに添付する。

該当ページは **`index.md`（生糧品規格書の全452品目 → PDFページ番号の索引）** で引く。例：内訳書に「納豆（冷）」とあれば索引で 51 を探し、印刷ページ「13」をそのまま Chrome の印刷画面に入れる。

### 規格書が要るのは生糧品の案件だけ
- 渡された規格書は **「生糧品規格書」**（生鮮・冷凍・惣菜・パン・弁当など 452 品目）。生糧品の案件ではこの該当ページを添付する。
- **貯糧品の案件（内訳書の表題が「貯糧品調達要求内訳書」、調味料・缶詰など）は規格書なし。内訳書に書いてあることがすべて。** 内訳書の「糧食品規格書のとおり」という文言は無視し、品名＋指定銘柄＋単位で探す。
- 価格は Excel で「基準量（◯g・◯ml）あたり」の指定価格として渡し、それを超える商品を探させる。容量の範囲も指定できる。
